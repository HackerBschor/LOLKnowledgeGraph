# Knowledge Graph - based League of Legends Analysis 🌐🎮

## Installation

### Database

```postgresql
CREATE DATABASE <database>;
CREATE USER <user> WITH PASSWORD '<password>';
ALTER DATABASE <database> OWNER TO <user>;
GRANT ALL ON database <database> TO <user>;
```
### Config File

```ini
[PostgreSQL]
host=<host>
database=<database>
user=<user>
password=<password>
```
